# AutoLuxuries – app del negocio

App instalable (PWA) para AutoLuxuries Auto Detailing: citas, clientes y vehículos (autos, botes, RV), cobros, cotizaciones, membresías y lista de precios.

- Datos: Firebase (proyecto `autoluxuries`), Firestore + inicio de sesión con correo.
- Reglas de seguridad: `firestore.rules` (pégalas en Firestore → Rules).
- Se publica con GitHub Pages desde la rama `main`.
- Funciona sin señal; al abrirla con internet recibe las mejoras sola.
